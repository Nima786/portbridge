Connect Your Cloudflare Account

Use a scoped Cloudflare API Token so the panel can list your domains and manage DNS records without needing your account password or Global API Key.

  1. In your Cloudflare dashboard, click the Profile icon (top-right) → My Profile → API Tokens → Create Token.
  2. Next to the Edit zone DNS template, click Use template.
  3. Under Permissions: the first row is already set to Zone → DNS → Edit. Click + Add more right below it and set the new row to Zone → Zone → Read.
  4. Under Zone Resources: change the second dropdown from Specific zone to All zones (or keep Specific zone and select the domain you want to use).
  5. Click Continue to summary → Create Token, then copy the token shown and paste it below.
